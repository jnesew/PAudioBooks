# UI design

Paper List is the selected visual baseline: warm ivory and forest in Light,
forest-charcoal and sage in Dark, relaxed spacing, readable sans-serif type, and
native controls. See [UI specification](PROTOTYPE_TARGETS.md) for current
presentation and interaction rules, and [the product design](../DESIGN_PLAN.md)
for complete behavior.

All image boards, candidates, prompts, iteration notes, and device captures belong
in gitignored `docs/local/design/`. The boards predate later UI modifications and
are historical references. Use the written specification for current styling and
behavior. Images do not establish tested contrast, accessibility, playback, or
device compatibility.
