# Documentation assets

`obtainium.png` is the unmodified official “Get it on Obtainium” badge from
[Obtainium's graphics](https://github.com/ImranR98/Obtainium/blob/main/assets/graphics/badge_obtainium.png),
copied locally as recommended by its
[badging guide](https://wiki.obtainium.imranr.dev/deep_links/#badging-your-project).
The README displays it at 200 pixels wide, including its original transparent
padding, and links to the PAudioBooks Obtainium configuration.

The badge belongs to the Obtainium project and retains its upstream GNU General
Public License version 3. A copy of the
[upstream license](https://github.com/ImranR98/Obtainium/blob/main/LICENSE.txt)
is included in [obtainium-LICENSE.txt](obtainium-LICENSE.txt). It is a third-party
documentation asset and is not included in the Android app.
